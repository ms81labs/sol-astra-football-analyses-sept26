# Archive Conventions

Live operating docs stay in place:
- `SESSION-HANDOFF.md`
- `README.md`
- `docs/superpowers/plans/2026-04-11-active-now-systematic-roadmap.md`
- current product and research docs that still describe the active lane

Archive retired material under `docs/archive/`:
- closed sprint notes
- superseded research or analysis
- historical root notes worth keeping for reference

Delete obvious scratch or dump files instead of archiving them:
- generated code dumps
- temporary improvement lists
- one-off mission notes that are not source of truth
