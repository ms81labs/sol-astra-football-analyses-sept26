# ADR-001 Camera support

- Status: accepted
- Owner: backend/media
- Decision: first automatic profile is a declared stitched panoramic/tactical camera after distortion and coverage are characterised. Other media may be tagged manually.
- Alternatives: generic arbitrary-camera automation; broadcast-with-cuts as the first automatic profile.
- Evidence: v1.1 plan §3.1 and §4.1; current independent accuracy is unproven.
- Reversibility: high (profile is a declaration, not a rewrite).
- Reconsider when: an independent labelled corpus exists for another camera class.

# ADR-002 Coordinate conventions

- Status: accepted
- Owner: CV
- Decision: keep source frame/PTS, processing sample and match clock as separate identities. Pitch coordinates require a versioned calibration object; four-point homographies remain readable.
- Alternatives: frame-index / nominal-fps timestamps; silent promotion of four-point fits to whole-pitch truth.
- Reversibility: readers stay additive.
- Reconsider when: a distortion-corrected mapping passes withheld-region checks.

# ADR-003 Persistence

- Status: accepted
- Owner: backend
- Decision: SQLite transactional metadata plus immutable run artifacts. Workbench corrections are append-only JSONL. No vector database or broker until a measured workload needs one.
- Reversibility: high.

# ADR-004 Detector licensing

- Status: accepted
- Owner: lead
- Decision: record exact code/weight licences before promotion. Ultralytics AGPL/Enterprise terms are reviewed per asset, not generalised.
- Reversibility: adapter-replaceable.

# ADR-005 AI routing

- Status: accepted
- Owner: backend
- Decision: language assistance is optional. Policy router falls back to deterministic templates when providers are disabled. Fabricated evidence IDs are rejected. No request may change a measurement.
- Reversibility: disable providers by policy.

# ADR-006 Cloud region

- Status: accepted
- Owner: operations
- Decision: Daytona remains the private ephemeral worker. GPU region requests are not assumed. No new cloud run is authorised by this implementation.
- Reversibility: local CPU path remains the fallback.

# ADR-007 Capability release

- Status: accepted
- Owner: lead
- Decision: release by independently visible capability status. Manual review can ship while tracking acceptance is pending. Physical metrics stay unavailable until identity and calibration gates pass.
- Reversibility: feature flags / capability matrix.
